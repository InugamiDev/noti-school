# Dependency policy and research receipt

Researched 2026-09-25 local time through primary documentation and npm registry metadata. Exact versions
are frozen in manifests; pnpm lock is generated by pnpm 10.29.2. No caret/tilde direct dependencies.
Catalog pins for absent apps become lock importers only when those apps arrive. Do not present unused
catalog/workspace dependencies as installed or compiled. No provider SDK needed in foundation.

Better Auth uses its core schema, direct PostgreSQL adapter and programmatic migration export. Current
CLI is `auth`; `@better-auth/cli` resolves to older 1.4.21 and is deliberately not selected. No automatic
live database schema generation was run. Auth worker must test session invalidation and migration behavior
against the pinned package; email/OAuth presence alone does not verify delivery or credentials.

[PM2 declaration](https://pm2.keymetrics.io/docs/usage/application-declaration/) supports native interpreter
selection and restart/shutdown controls. [Cloudflare ingress](https://developers.cloudflare.com/tunnel/features/locally-managed-tunnels/configuration-file/)
documents syntax validation and first-matching-rule testing. Local cloudflared 2026.8.2 validates the
candidate only. Existing host PM2 version remains coordinator-owned and was not changed.

OpenAI chat model deliberately has no guessed default or price. `text-embedding-3-small` dimension 1536
is retained from approved requirements; API worker must verify account availability and all current
generation/embedding/tool prices before enabling live calls. Jev English preference requires bilingual
evaluation; this foundation makes no measured retrieval, citation-support or Vietnamese-quality claim.

RAG-1 reuses the existing Rust/HTTP dependencies and configured OPENAI_CHAT_MODEL for strict Responses reranking and typed evidence/support checks. No new model default, price, provider SDK or dependency is introduced. Jev remains pinned for explicit EVIDENCE_PROVIDER=jev.
